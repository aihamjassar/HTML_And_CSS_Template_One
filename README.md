# Leon — HTML & CSS Template

> A responsive static website template titled **Leon**, implemented with semantic HTML, custom CSS, normalization styles, and icon assets.

## Overview

This repository contains the source and supporting files for **Leon — HTML & CSS Template**. The documentation below was prepared from the current repository structure and implementation files so that setup expectations, project boundaries, and implemented capabilities are explicit.

## Technology

| Area | Implementation |
| --- | --- |
| Markup | HTML page structure for the public-facing template |
| Styling | Custom CSS, Normalize.css, and Font Awesome assets |
| Delivery | Static files suitable for GitHub Pages or any web server |

## Key capabilities

| Area | Current implementation |
| --- | --- |
| Responsive layout | Provides a single-page presentation template. |
| Reusable styles | Keeps page styling in dedicated CSS files. |
| Deployment readiness | Can be published as static content without a server runtime. |

## Getting started

Use the following workflow to work with the project locally.

```bash
git clone https://github.com/aihamjassar/HTML_And_CSS_Template_One.git
cd HTML_And_CSS_Template_One
python3 -m http.server 8000
# Open http://localhost:8000 in a browser
```

## Project structure

| Path | Purpose |
| --- | --- |
| index.html | Main template page |
| css/ | Site, normalization, and icon styling |
| images/ | Visual assets used by the page |
| webfonts/ | Bundled icon font assets |

## Configuration notes

No compilation step is required. Use a local static server during development so browsers load assets consistently.
